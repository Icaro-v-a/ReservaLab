# Bibliotecas JDBC

Esta pasta recebe as bibliotecas baixadas automaticamente pelo script `ferramentas/PrepararDependencias.java`.

Execute `preparar_jdbc.bat` (Windows) ou `./preparar_jdbc.sh` (Linux/macOS) com internet, uma única vez. Depois, o ReservaLab pode ser executado sem internet.

As bibliotecas esperadas são:

- sqlite-jdbc-3.54.1.0.jar (Xerial)
- slf4j-api-2.0.17.jar
- slf4j-nop-2.0.17.jar

Fonte: Maven Central. Veja `LICENCAS_E_DEPENDENCIAS.md`.
